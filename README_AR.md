# منظومة المختبرات الطبية ومصارف الدم — النسخة المركزية

## الفكرة
منظومة ويب متجاوبة تعمل من الهاتف والكمبيوتر، بقاعدة بيانات مركزية.
النسخة مصممة لتكون أساسًا للتوسع على مستوى ليبيا.

## التشغيل المحلي
1. ثبّت Python 3.12 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   `pip install -r requirements.txt`
4. شغّل:
   `python run.py`
5. افتح المتصفح على `http://127.0.0.1:8000`

الحساب التجريبي:
- المستخدم: `admin`
- كلمة المرور: `admin123`

## النشر
المشروع يحتوي `render.yaml` و`Dockerfile` و`Procfile`.
يمكن نشره على خدمة استضافة تدعم Flask وPostgreSQL. لا تستخدم خادم Flask التطويري في الإنتاج؛ توصي وثائق Flask باستخدام خادم WSGI مثل Gunicorn. 

## قبل الاستخدام الرسمي
- تغيير كلمة مرور المدير.
- ضبط SECRET_KEY.
- استخدام HTTPS.
- إنشاء حسابات وصلاحيات حقيقية.
- تفعيل النسخ الاحتياطي الدوري.
- إضافة شعار وبيانات وزارة الصحة.
- مراجعة حقول الحصر النهائية مع الإدارة.
